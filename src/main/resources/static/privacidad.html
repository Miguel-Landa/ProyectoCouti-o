Aviso de privacidad

Responsable

MRX Taller de Motocicletas es responsable de los datos personales que se capturan en este sistema.

Datos que se recaban

Nombre del cliente, teléfono, datos de la motocicleta, historial de servicios, ventas y cobros, y los datos de acceso del personal.

Finalidad

Se usan solo para registrar ventas, citas, servicios, cobros y control de inventario. No se venden ni se comparten con terceros.

Protección

Los datos se guardan en una base de datos protegida y las contraseñas se almacenan cifradas. Solo el personal autorizado puede consultarlos según su rol.

Derechos del titular

Puede solicitar el acceso, la corrección o la eliminación de sus datos acudiendo al taller.
